# Custom Music Player (Forge 1.12.2)

Плеер mp3 внутри Minecraft. Клавиша **M** открывает окно плеера.

Положи mp3 в папку `custom_music` (в папке игры) и нажми «Обновить».

## Возможности
- список треков с прокруткой и поиском по названию/исполнителю/альбому (теги ID3)
- перемотка: перетаскивание ползунка, кнопки -10/+10, стрелки влево/вправо
- громкость: ползунок, колесо мыши, стрелки вверх/вниз
- режимы «Случайно» и «Повтор» (выкл / все / трек)
- любимые треки: сердце справа или ПКМ по треку в списке
- настройки сохраняются в `config/custommusic.properties`

Горячие клавиши (когда поиск не в фокусе): Пробел - пауза, M/Esc - закрыть.

Сборка: см. README-BUILD.md (GitHub Actions).
